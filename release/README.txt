SonyMute
========

Double-press the NC/AMB button on a Sony WH-1000XM5 to mute or unmute all microphones.

Requirements
------------
This build needs the .NET 10 Runtime installed. The SDK is NOT needed.

  https://dotnet.microsoft.com/download/dotnet/10.0

Pick ".NET Runtime 10.x" for Windows x64. The ".NET Desktop Runtime" also works.

Don't want to install anything? Download SonyMute-<version>-portable.exe from the
same release instead. It has the runtime built in.

Usage
-----
Run SonyMute.exe. It sits in the tray. Left click toggles mute, right click opens the menu.
Settings: %APPDATA%\SonyMute\settings.ini

https://github.com/jvinkovic/SonyMute
